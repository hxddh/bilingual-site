隐私政策

对读是一个在浏览器里运行的翻译扩展。开发者不运营任何服务器，不收集、不出售、也不接收你的任何数据。扩展里没有统计、广告或追踪代码。

本地翻译（默认）

默认使用 Chrome 内置的翻译模型，网页文字只在你的电脑上处理，不会发送到任何地方。第一次翻译某种语言时，由 Chrome 自己下载对应的官方语言包；对读不下载、也不附带任何模型。

精译（可选）

只有你在设置里填写了自己的密钥，并且选择了“精译”，或者在本地翻译不支持的页面上点了“改用精译”时，扩展才会把你要看的段落文字，以及用于统一术语的页面正文（最多约 12,000 个字符），从你的浏览器直接发送给你选择的服务商。这些数据由该服务商按其隐私政策处理，不经过开发者的任何服务器。

保存在你电脑上的数据

  • 设置和各网站的显示方式：保存在 Chrome 的同步存储中。如果你开启了 Chrome 同步，会在你的设备之间同步。
  • 自带密钥：只保存在这台电脑上扩展自己的存储里，网页无法读取，不同步。
  • 已翻译的段落（原文与译文）：保存在扩展自己的本地数据库中，最多约 4 万条，旧的会自动清除；可在设置中一键清除。
  • 你改过的术语译法：按网站保存在这台电脑上。
  • 无痕窗口：不保存各网站的显示方式、排版和术语，也不保存译文；关闭窗口后不留记录。

权限

  • activeTab、scripting：在你点击扩展图标或按快捷键时，在当前页面显示译文。
  • storage：保存上面列出的设置和译文。
  • 网站访问权限（可选）：只在你打开某个网站的开关，或填写精译服务商地址时，才申请对应网站的权限。

權限

Privacy policy

Bilingual is a translation extension that runs in your browser. The developer runs no servers and does not collect, receive or sell any of your data. The extension contains no analytics, advertising or tracking code.

On-device translation (default)

By default Bilingual uses Chrome's built-in translation model. Page text is processed on your computer and is not sent anywhere. The first time a language is used, Chrome itself downloads its official language pack; Bilingual doesn't download or ship any model.

Precise translation (optional)

Only if you add your own API key and either choose Precise or click “Use Precise translation” on a page that on-device translation doesn’t support, the extension sends the paragraphs you ask to see, plus up to about 12,000 characters of the page's main text used to keep terms consistent, directly from your browser to the provider you chose. That provider handles the data under its own privacy policy. Nothing passes through any server of the developer.

Data stored on your computer

  • Settings and per-site display choices, in Chrome's sync storage. If Chrome Sync is on, they sync across your devices.
  • Your API key, stored only on this computer in the extension’s private storage, which web pages cannot read. It is never synced.
  • Translated paragraphs (original and translation), in the extension's own local database, up to about 40,000 entries with old ones removed automatically. You can clear them in Settings.
  • Term translations you edit, stored per site on this computer.
  • In Incognito windows, nothing is kept per site (display choice, layout, terms) and no translations are stored; nothing remains after you close the window.

Permissions

  • activeTab, scripting: show translations on the current page when you click the icon or use the shortcut.
  • storage: keep the settings and translations listed above.
  • Site access (optional): requested only for a site you switch on, or for the endpoint of the Precise provider you enter.

プライバシーポリシー

対読はブラウザ内で動く翻訳拡張機能です。開発者はサーバーを運営しておらず、あなたのデータを収集・受信・販売しません。解析、広告、トラッキングのコードは含まれていません。

端末内翻訳（既定）

既定では Chrome に内蔵された翻訳モデルを使います。ページの文章はあなたの端末内で処理され、どこにも送信されません。ある言語を初めて使うときは、Chrome 自身が公式の言語パックをダウンロードします。対読がモデルをダウンロードしたり同梱したりすることはありません。

高精度翻訳（任意）

自分の API キーを入力したうえで、高精度翻訳を選んだ場合、または端末内翻訳が対応していないページで「高精度翻訳を使う」を押した場合に限り、表示を求めた段落と、用語をそろえるためのページ本文（最大約 12,000 文字）が、あなたのブラウザから選んだプロバイダーへ直接送信されます。データはそのプロバイダーのプライバシーポリシーに従って扱われ、開発者のサーバーは一切経由しません。

端末に保存されるデータ

  • 設定とサイトごとの表示方法：Chrome の同期ストレージに保存され、Chrome 同期が有効ならデバイス間で同期されます。
  • API キー：この端末の拡張機能専用の領域にのみ保存され、ウェブページからは読み取れません。同期されません。
  • 翻訳済みの段落（原文と訳文）：拡張機能専用のローカルデータベースに最大約 4 万件保存され、古いものは自動で削除されます。設定から消去できます。
  • 修正した用語の訳：サイトごとにこの端末に保存されます。
  • シークレット ウィンドウでは、サイトごとの表示方法・レイアウト・用語や訳文を保存しません。ウィンドウを閉じると何も残りません。

権限

  • activeTab、scripting：アイコンを押すかショートカットを使ったとき、現在のページに訳文を表示します。
  • storage：上記の設定と訳文を保存します。
  • サイトへのアクセス（任意）：スイッチを入れたサイト、または入力した高精度翻訳プロバイダーのエンドポイントに対してのみ要求します。
